# 将本模型做成 PPT 的建议说明报告

> 目的：把"模型构建 + 作业交付"压缩成一次 15 分钟的课堂展示
> 适用：课程汇报、项目答辩、作品集演示
> 配套材料：`02-construction-process.md`（内容来源）、`01-usage-and-simulation.md`（演示脚本）

---

## 1. 先定调：这次展示要证明什么

课程作业的评分点通常不是"收益多高"，而是：

| 评分维度 | 你要证明的 | 用哪几页 |
| --- | --- | --- |
| 问题定义清楚 | 知道自己在预测什么、为什么 | P3–P5 |
| 方法正确 | 防泄漏、时间切分、校准 | P6–P8 |
| 工程完整 | 能跑、能复现、有测试 | P11 |
| 有批判性 | 敢报告负面结果 | P10 |
| 表达清楚 | 一页一个观点 | 全部 |

**一句话主线**：
> 我搭了一个"风险预算 + 持仓诊断"的流水线；它不保证选股赚钱，但能说清每个组合的风险与依据。

这条主线要在 P1 就抛出来，后面每页都往回收。

## 2. 页面结构（14 页，15 分钟）

### P1 封面（20 秒）

- 标题：**QuantGuard v2：从行情快照到可解释的组合建议**
- 副标题：数据 → 分位数模型 → 区间校准 → 风险阶梯 → 持仓诊断
- 角标：姓名 / 学号 / 日期
- 视觉：右侧放网页首页截图（`/v2.html`），一眼看出"有成品"

### P2 问题：三个没人回答的问题（40 秒）

- 我要买什么？
- 我该买多少、留多少现金？
- 我现在的持仓有没有问题？

一句话："市面上不缺选股信号，缺的是把信号翻译成**仓位与风险**的那一层。"

### P3 数据：为什么是 2500 天（60 秒）

- 大字：**997 只 × 2500 个交易日 = 205 万行**
- 小字：2011–2026，63 个行业，前复权
- 图：**独立窗口随天数增长**的柱状图（267 天→8 个，2500 天→133 个）
- 口播："过拟合的约束是时间上的独立样本，不是行数。"

### P4 数据获取的坑（40 秒，加分项）

- 四个数据源被限流的表格（东财主站/分片、腾讯 501、baostock 慢）
- 最终方案：腾讯 proxy 分页，**6 分钟抓完 998 只**
- 口播："免费数据源里，稳定性比数据量更稀缺。"

### P5 标签与防泄漏（60 秒）

- 标签：未来 N 日收益 − 行业中位数
- N = 5 / 20 / 60（三档，已从五档收敛）
- 红线：`标签结束日 ≤ 信号日 − 5 个交易日`
- 图：一条时间轴，标出"信号日 / embargo / 标签结束日"
- 口播："这一条纪律，比模型结构重要得多。"

### P6 模型：为什么是分位数（60 秒）

- 不预测"涨多少"，预测 **P10 / P50 / P90**
- 理由：风险预算需要"可能跌多少"
- 图：一根蜡烛状的分位数带 + 实际值落点
- 小字：LightGBM，10 个特征，3 种子

### P7 校准：从 15% 到 10%（60 秒）

- 三行表：未校准 14.6% / 静态 CQR 16.8% / 自适应 ACI 10.2%
- 图：三根柱子的破坏率对比 + 一条 10% 基准线
- 口播："不校准的话，'最差情况'是假的。"

### P8 组合：为什么放弃线性规划（60 秒）

- 左：LP 的夏普 0.09–1.00
- 右：排序+逆波动的夏普 1.47–1.72（1000 日样本）
- 结论："弱信号下，优化器会把估计误差当机会放大。"
- 图：两行并列的夏普条形图

### P9 风险阶梯与选股（60 秒）

- 五档表格：CVaR 4%→18%、持仓 50→8、现金 76%→15%
- 右侧：一张"平衡档 15 只"的推荐表（排名 / 行业 / 权重）+ 一行"只买前 5 只"的放大结果
- 口播："同一套信号按风险偏好切成五档；它只推荐，买不买由投资人决定。"

### P10 结果与反证（90 秒，全场重点）

- 上半：信号层——20 日 Rank IC 0.0535，Top 超额 0.73%，覆盖 10.1%
- 下半：组合层——10 年回测年化 9.5%/19.1%，夏普 0.46/0.67，**低于等权基准 0.93**
- 大字结论：**"短期正超额是区间性的，不能宣称稳定 alpha。"**
- 口播："我把这个负面结果放进报告，因为它决定了产品的定位。"

### P11 工程与验收（40 秒）

- 35 项测试、8 项验收、快照 SHA256、证据包 token 上限
- 一句话："换个人接手，能跑起来、能复现、能核对。"

### P12 局限（40 秒）

- 行业为当前分类（前视偏差）
- 幸存者偏差
- 成本为估算
- 60 日档仅 43 个窗口

### P13 结论（40 秒）

- 能做：风险阶梯、推荐组合与权重、六维诊断、调仓参考
- 不能做：稳定选股 alpha
- 定位：**风险预算 + 持仓诊断工具**

### P14 Q&A（备用）

预置三个问题的答案（见第 5 节）。

## 5. 预置问答

| 提问 | 回答要点 |
| --- | --- |
| "IC 0.05 是不是太低了？" | 横截面日频 IC 0.05 已可交易；关键是 Top 组超额和扣费后表现，不是绝对值 |
| "为什么跑输等权基准还敢交？" | 正因为它没跑赢，我才把定位改成风险预算工具；报告里写清了 |
| "为什么关掉元模型？" | 三份快照 AUC 0.51–0.56，没有可测增益；留着只增加复杂度 |
| "数据从哪来，能复现吗？" | 公开接口 + 快照 SHA256 + 一条命令重跑；采集器可替换 |
| "为什么只有 3 个期限？" | 10/40 日没有独立窗口支撑，留着等于给没有依据的选项 |
| "实盘能用吗？" | 不能直接实盘：没建模涨跌停排队、滑点是估算、未接交易接口 |
