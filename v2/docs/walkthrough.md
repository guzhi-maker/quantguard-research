# 一次完整使用示范：从采集数据到选出股票

本文用真实运行结果演示整条链路：**采集 → 启动分析 → 读输出 → 选股 → 对已有持仓给建议**。
所有数字都来自 `v2/artifacts/walkthrough_run.json` 与 `walkthrough_console.log`，可复现。

本次使用的快照：`RAW-20261119-124359-05EA7E`（300 只 × 约 1000 个交易日）。
参数：`--risk 5.5 --horizon 2`，即平衡档、20 日标签；模拟持仓 3 只。

---

## 步骤一：确认环境

```powershell
python -m pytest v2/tests -q
```

输出 `27 passed` 表示环境可用（本次耗时约 4 分钟）。缺依赖时先 `pip install -r requirements.txt`。

## 步骤二：采集数据

```powershell
python data_agent/collect_dataset.py --universe-size 300 --history-days 1000 --no-quotes
```

程序逐只抓取并实时打印进度，最后输出：

```text
采集完成
  快照编号: RAW-20261119-124359-05EA7E
  股票数量: 300
  证券-日行数: 286522
  实时行情行数: 0
  日期范围: 2022-08-29 ~ 2026-11-19
  失败记录: 0
  重复键: 0
  非法价格行: 0
  manifest: data/manifests/RAW-20261119-124359-05EA7E.json
```

这些字段的含义：

| 字段 | 含义 | 怎么判断好坏 |
| --- | --- | --- |
| 快照编号 | 本次数据的唯一 ID，后续所有分析都引用它 | 记下来，报告里要写 |
| 股票数量 | 实际抓到的股票数，可能少于请求值（ST/退市/流动性过滤） | 300 就是 300 |
| 证券-日行数 | 所有股票 × 所有交易日 | 300 × 1000 量级 |
| 实时行情行数 | 本次用了 `--no-quotes`，所以是 0；研究不需要 | 0 属正常 |
| 日期范围 | 数据覆盖区间 | 要覆盖你想研究的期限 |
| 失败记录 | 抓取失败的股票/字段 | **0 最好** |
| 重复键 | 同一天同一只股票出现两次 | **必须 0** |
| 非法价格行 | 负价、零价等 | **必须 0** |

数据落在 `data/raw/RAW-.../market_daily.csv`，`data/manifests/` 下是带 SHA256 的清单。

## 步骤三：启动分析

```powershell
python v2/cli.py run --run-id RAW-20261119-124359-05EA7E --risk 5.5 --horizon 2 `
  --holdings "002242:0.25,601857:0.20,300760:0.15" `
  --out v2/artifacts/walkthrough_run.json
```

程序会训练模型、做滚动验证、解五档组合、诊断持仓、生成建议，最后打印摘要：

```text
快照 RAW-20261119-124359-05EA7E　截止 2026-11-19　偏好 平衡 / 中
模型 qg-v2/lightgbm/20d/12f　训练 240971 行
分位覆盖率 P10 14.6% / P90 15.5%　RankIC 0.059　Top 超额 0.0135　元模型 AUC 0.541
有效独立样本 43（20 日标签）
验证方式 walk_forward　抽样折 3
...
```

逐行解释：

| 行 | 含义 |
| --- | --- |
| 快照 / 截止 | 用的哪份数据、数据截止到哪天 |
| 模型 `qg-v2/lightgbm/20d/12f` | 版本 / 算法 / 20 日标签 / 12 个特征 |
| 训练 240971 行 | 参与训练的样本行数（股票 × 日期） |
| 分位覆盖率 P10/P90 | **未校准**的区间破坏率，理想各 10% |
| RankIC 0.059 | 排序能力：分数与未来收益的秩相关，>0.02 才算有信号 |
| Top 超额 0.0135 | 分数最高 20% 的组合比全市场均值多赚 1.35%（20 日） |
| 元模型 AUC 0.541 | 判断“这次预测靠不靠谱”的能力，0.55 是启用门槛 |
| 有效独立样本 43 | 20 日重叠标签下真正独立的窗口数 |
| 验证方式 | 滚动前推 3 折，不是随机切分 |

## 步骤五：关键指标怎么读

本次的实际值：

| 指标 | 本次值 | 读法 |
| --- | --- | --- |
| 未校准 P10/P90 | 14.6% / 15.5% | 原始区间偏窄（>10% 说明跌出去太多） |
| **校准后 P10/P90** | **10.2% / 10.4%** | 自适应校准后回到名义水平，可用 |
| RankIC | 0.059（IR 1.74，胜率 67.5%） | 有排序能力，但不算强 |
| 独立 IC | 0.077（24 个独立日期） | 去掉重叠后反而更高，信号相对稳 |
| Top 组超额 | 1.35% | 选头部比选平均多赚 1.35%/20 日 |
| 元模型 AUC | 0.541 | 未达 0.55 → 自动关闭仓位乘数 |
| 有效独立样本 | 43 | 统计上可用，但不算多 |

注意：覆盖率一栏打印的是**未校准**数字，验收项用的是**校准后**数字，两者不一致是正常的。

## 步骤六：风险阶梯

| 档位 | CVaR | 预期月收益 | 波动 | 仓位 | 持仓 | 现金 | 成本 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 保守 | 4.0% | -0.11% | 6.6% | 27.9% | 22 | 72.1% | 0.06% |
| 稳健 | 6.0% | -0.15% | 10.1% | 37.4% | 18 | 62.6% | 0.09% |
| 平衡 | 9.0% | -0.20% | 15.3% | 50.5% | 17 | 49.5% | 0.12% |
| 进取 | 13.0% | -0.30% | 21.0% | 71.2% | 11 | 28.8% | 0.16% |
| 激进 | 17.8% | -0.34% | 28.0% | 90.6% | 12 | 9.4% | 0.21% |

三个要点：

1. **CVaR 与波动随档位上升，排序正确**（CVaR 4% → 17.8%）。
2. **现金很多**：波动目标 16% 对一群波动 30% 左右的成长股来说太低，只能靠降仓位达标。
   保守档 72% 现金不是 bug，是风险预算的结果。
3. **预期收益全为负**：这是扣费后的月超额，且优化器以“预期收益 − 风险惩罚”为目标。
   当风险惩罚占主导时，它会选低风险标的，算出来的净收益可能略负。
   **含义是“当前没有划算了的机会”，不是“模型让你亏钱”。**

## 步骤八：已持股诊断（六维）

| 维度 | 状态 | 证据 | 建议动作 |
| --- | --- | --- | --- |
| 偏好一致性 | 关注 | 实际波动 23.8%，声明档位目标 16%，比值 1.49 | 减仓高波动持仓 |
| 合规性 | **需处理** | 3 只超单票 8%，1 个行业超 22% | 优先处理超限项 |
| 可持有性 | **需处理** | 中国石油、迈瑞医疗当日不可交易 | 分批退出，不补仓 |
| 风险集中 | 关注 | Top3 权重 60%，HHI 0.125 | 降低同质持仓 |
| 机会成本 | 正常 | 与目标差异 102%，预期改善 -0.01%、成本约 0.20% | 换仓不划算 |
| 交易行为 | 正常 | 0 只碎片仓位 | 维持 |

结论：**你的持仓比声明的风险更激进，且有超限和不可交易标的，先处理合规问题，再谈优化。**

## 步骤九：加减仓建议

预算 2 条（持仓 ≤10 只），安全类不占预算。本次输出 3 条安全 + 2 条优化：

| 代码 | 动作 | 变动 | 类型 | 原因 |
| --- | --- | --- | --- | --- |
| 002242 九阳股份 | 减仓 | -20.7% | 合规 | 当前 25% 超过单票 8% 上限 |
| 300760 迈瑞医疗 | 减仓 | -15.0% | 可持有性 | 当日不可交易，需等可卖 |
| 601857 中国石油 | 减仓 | -20.0% | 可持有性 | 当日不可交易，需等可卖 |
| 688802 沐曦股份-U | 买入 | +4.3% | 再平衡 | 目标 4.3% 与当前 0% 偏离 |
| 301396 宏景科技 | 买入 | +0.4% | 再平衡 | 权重偏离，金额很小 |

三个细节：

1. **安全类不占预算**，所以合规/不可交易的三条必须执行。
2. **每条都有成本与改善两个数**：例如沐曦买入改善 0.023%、成本 0.0099%，
   过闸（改善 > 成本 × 2）才会出现。
3. **交易包自洽检查**：`post_check.feasible = true`，执行后没有新的超限。

实际下单时还要注意：301396 显示“买入 0 手”，是因为金额不足一手，属于名义建议。

## 步骤十：证据包与 AI 简报

`evidence` 是给大模型的输入，共六块，本次约 **2,423 token**（上限 5,000）：

| 块 | 内容 |
| --- | --- |
| meta | 快照、截止日、模型版本、提示词版本、数据哈希 |
| user | 风险档、期限、是否持股、资金区间 |
| portfolio | 五档阶梯与拒单率 |
| stocks | 持仓/候选的 P10/P50/P90、可信度、乘数、可交易性、归因 |
| diagnosis / advice | 六维结论与建议清单 |
| limits | 数据与方法的边界声明 |

加 `--report` 会把它交给 DeepSeek 写中文简报；没有密钥时回退模板，
并在 `report.error` 里写明原因。AI **不允许计算或改写数字**，只做解释。

## 步骤十一：验收项

| 项 | 本次 | 含义 |
| --- | --- | --- |
| `coverage_ok` | ✅ | 校准后区间达标 |
| `calibration_ok` | ✅ | 自适应校准生效 |
| `ic_ok` | ✅ | RankIC 0.059 > 0.02，排序可用 |
| `meta_auc_ok` | ❌ | 0.541 < 0.55，仓位乘数被关闭（`warnings` 已说明） |
| `cvar_monotonic` | ✅ | 五档风险排序正确 |
| `reject_rate_ok` | ✅ | 拒单率在阈值内 |
| `evidence_size_ok` | ✅ | 证据包未超限 |
| `leakage_free` | ✅ | 无未来数据泄漏 |

**决策规则**：`ic_ok` 与 `calibration_ok` 是两条硬线。
前者不过 → 名单只能当分散参考；后者不过 → “最差情况”不可信。
`meta_auc_ok=false` 不影响选股，只说明少了一层置信度加权。

## 结论：这次该怎么做

1. **组合层面**：按平衡档建仓，但只买得起 10 只，实际投入约 38.6%，剩现金。
2. **不要满仓**：波动目标 16% 与这群股票的波动不匹配，满仓会超出预算。
3. **持仓层面**：先处理 3 只超限 + 2 只不可交易，再考虑买入新标的。
4. **预期要现实**：五档扣费后月收益都是 -0.1% 到 -0.3%，说明当前不是进攻时机。
