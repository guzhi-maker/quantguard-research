# QuantGuard 量化研究终端：期末项目设计规范

**日期：** 2026-11-04  
**状态：** 待用户审阅  
**目标交付：** 一个可在课堂现场稳定演示、可作为课程报告提交、能讲清楚量化研究全流程的个人 A 股研究应用。

## 1. 项目定位

QuantGuard 不是荐股页面，也不是模拟下单平台。它应当模仿量化研究团队的日常工作方式，把一次研究拆成可复核的链路：

1. 提出研究问题。
2. 获取并检查数据。
3. 定义可计算因子。
4. 建立横截面选股模型。
5. 用含交易成本的规则回测。
6. 分析收益来源、风险和容量。
7. 构建目标组合并生成风险行动。
8. 形成研究备忘录并保留结果记录。

核心研究问题：

> 在高流动性 A 股股票池中，横截面动量、低波动和流动性因子能否在计入 A 股交易约束后形成稳定超额收益？

应用必须诚实展示结论，包括负收益、弱因子、成本侵蚀、样本偏差和策略失效，不只呈现最好结果。

## 2. 成功标准

期末展示时需要满足以下标准：

- 可以在课堂网络不可用或东方财富接口异常时，明确切换到内置演示数据，完整跑通全流程。
- 实时与演示数据必须有明显标识，不能把演示结果描述为实时行情。
- 一次研究请求能够输出数据覆盖、因子定义、IC/ICIR、毛收益、净收益、交易成本、回撤、换手、基准超额和目标持仓。
- 回测能区分探索区间与留出区间，避免只用全样本结果证明策略有效。
- 5 万元个人账户的目标持仓必须是 100 股整数手，并显示实际股数、现金、最低佣金和建仓成本。
- 研究结果可以导出为 Markdown 研究报告和 JSON 原始数据。
- 最近研究记录可保存、比较和重新载入参数。
- 老师可以在三分钟内通过展示导览看懂研究问题、方法、证据、风险和个人资金计划。
- 桌面和移动端无整页横向溢出，表格只在自身容器内滚动。
- 所有关键结果均可追溯至参数、数据模式、计算规则和生成时间。

## 3. 范围与非目标

### 3.1 本期范围

- 实时行情模式与可复现演示模式。
- 数据血缘和研究参数说明。
- 因子定义、因子覆盖率和 IC/ICIR 诊断。
- 横截面多因子选股和三种模型对照。
- 毛收益、净收益、成本分解和容量诊断。
- 探索期与留出期绩效。
- 目标组合、整手约束、风险建议和资金积累情景。
- 最近研究记录、报告导出和方法说明。
- 五步展示导览。

### 3.2 非目标

- 不连接券商账户，不发送真实交易指令。
- 不承诺收益，不给出确定性买卖结论。
- 不把当前股票池回测包装成严格历史成分回测。
- 不宣称固定因子模型经过了机器学习训练。
- 不实现高频、期货、期权或做空策略。
- 不在本期引入数据库服务器、用户系统或云部署。

## 4. 目标用户与展示场景

主要用户是使用 5 万元左右个人资金进行长期学习和研究的学生。用户关心的是研究过程是否可信，而不是频繁交易。

课堂演示分为五步：

1. **问题**：个人小资金是否需要机构级容量，如何用可复核方法寻找收益来源。
2. **数据**：展示股票池筛选、历史覆盖、行业信息、实时/演示模式和已知偏差。
3. **模型**：展示因子公式、标准化、权重、IC 与三种模型对照。
4. **收益**：展示毛收益、成本、净收益、回撤、换手、基准超额和留出期表现。
5. **执行**：同步目标组合，查看整手持仓、风险行动和 5 万元资金积累计划。

## 5. 研究流程与页面结构

主导航调整为：

- **研究总览**
- **策略实验室**
- **组合风控**
- **研究档案**

顶部增加研究状态条：

- 数据模式：实时行情 / 演示数据。
- 数据时间。
- 当前研究状态。
- “展示导览”入口。

### 5.1 研究总览

研究总览不是营销首屏，而是研究决策页，回答：

- 当前数据是否完整、何时更新、来自哪里。
- 当前模型和回测是否可运行。
- 净收益是否超过成本与基准。
- 最大回撤、因子 IC 和留出期是否支持继续研究。
- 当前组合风险等级和首要行动。
- 5 万元资金计划累计投入与保守情景。

页面顶部保留现有风险画像，但增加一条“研究证据摘要”，把数据覆盖、因子状态、净收益、成本和置信边界放到同一阅读区域。

### 5.2 策略实验室

保留现有回测与持仓面板，并新增：

- **研究假设卡**：说明本次研究问题和模型定义。
- **数据血缘卡**：股票池规则、有效样本数、历史长度、复权口径、数据模式、更新时间。
- **收益实现卡**：毛年化、成本拖累、净年化、基准年化、净超额。
- **研究稳健性卡**：探索期、留出期、IC、ICIR、换手、容量和模型对照。
- **最近研究记录**：保存最近 6 次运行摘要，可重新载入参数。

参数区保留资金、股票池、目标持仓、模型、调仓频率、清仓窗口、ADV、每月投入和积累年限。实时模式下所有请求写明 `data_mode=live`；演示模式写明 `data_mode=demo`。

### 5.3 组合风控

保留搜索、持仓、权重、风险画像、净值路径和行业暴露，并增加：

- 账户资金输入，默认 5 万元。
- 每只股票的目标金额、整手股数和实际金额。
- 风险建议附带人民币金额与股数换算。
- “从策略目标同步”操作保留，并显示同步来源与时间。
- 现金拖累说明：当整手约束无法使用全部资金时，明确解释剩余现金。

### 5.4 研究档案

研究档案是期末项目区别于普通股票工具的核心页面，包含：

- 研究摘要。
- 实验参数。
- 数据来源和血缘。
- 因子定义与公式。
- 回测协议和成本假设。
- 探索期、留出期与全样本结果。
- 模型对照。
- 目标持仓。
- 风险与局限性。
- 导出 Markdown 和 JSON。
- 最近研究记录。

## 6. 数据设计与血缘

### 6.1 实时模式

- 股票池：按东方财富公开行情中的成交额排序，取用户指定数量的高流动性 A 股。
- 行情字段：日期、开盘、最高、最低、收盘、成交量、成交额。
- 行业信息：优先使用行情接口返回的行业字段，缺失时标记“未分类”。
- 历史窗口：默认 252 个交易日。
- 复权口径：沿用现有接口的前复权价格，研究档案必须明确标注。
- 数据时间：写入每份结果的生成时间与行情更新时间。

### 6.2 演示模式

演示数据使用与实时行情相同的字段结构，由确定性规则生成固定股票池和历史序列：

- 固定随机种子。
- 固定行业分布。
- 固定的价格、成交额和历史长度。
- 所有结果标注“演示数据”。
- 演示模式不得调用外部网络。

演示模式的目标是保证课堂演示可重复，不是模拟一个必然盈利的策略。

### 6.3 数据质量与偏差

研究档案必须显示以下边界：

- 当前高流动性股票池存在幸存者偏差。
- 当前行业字段不代表严格历史时点分类。
- 前复权处理减少除权跳空，但不能消除所有历史数据差异。
- 缺失历史过多的股票会被排除，可能进一步引入选择偏差。
- 成交额参与率和冲击成本是研究近似，不是交易所成交承诺。

## 7. 因子与模型

### 7.1 因子定义

- 20 日动量：`close_t / close_{t-20} - 1`。
- 60 日动量：`close_t / close_{t-60} - 1`。
- 20 日波动：日收益率 20 日标准差乘以 `sqrt(252)`。
- 流动性：`log1p(20 日平均成交额)`。
- 低波动因子：取 20 日波动因子的负值。

### 7.2 截面标准化

- 每个交易日对每个因子做横截面 Z-Score。
- 对极端值按均值上下 3 个标准差截断。
- 缺失值不参与排序。
- 因子方向统一为“分数越高越优”。

### 7.3 三个模型

- 趋势均衡：20 日动量 35%、60 日动量 25%、低波动 20%、流动性 20%。
- 强动量：20 日动量 50%、60 日动量 30%、低波动 5%、流动性 15%。
- 低波防御：20 日动量 15%、60 日动量 20%、低波动 45%、流动性 20%。

三个模型共享数据、成本、行业上限和容量约束，便于横向比较。

### 7.4 因子检验

- 计算每个采样日期的因子分数与未来 20 日收益的 Spearman Rank IC。
- 报告 IC 均值、ICIR、IC 胜率和样本数。
- IC 只作为方向诊断，不单独证明策略可盈利。
- 因子状态分为“方向有效”“方向偏弱”“反向或不稳定”“样本不足”。

## 8. 组合构建

- 在有效因子候选股中按综合分排序。
- 单票目标上限 10%。
- 行业目标上限 22%。
- 使用逆波动分配初始权重。
- 受 ADV 参与率和清仓窗口约束。
- 排除一手金额超过单票预算的股票。
- 将目标权重转换为 100 股整数手。
- 因整手取整产生的剩余资金保留为现金。

目标持仓必须显示：

- 股票、行业、价格。
- 目标权重与实际权重。
- 实际股数与手数。
- 实际金额。
- 预计退出天数和冲击成本。
- 整手取整缺口与现金。

## 9. 回测与收益实现

### 9.1 时间协议

- 先保留至少 60 个交易日用于因子与均线计算。
- 可用回测区间按时间顺序划分为前 60% 探索期和后 40% 留出期。
- “探索期”用于理解因子行为和参数影响，不宣称模型经过参数优化。
- “留出期”只用于报告样本外表现，不参与调整模型权重。
- 主页必须同时显示全样本、探索期和留出期净收益。

### 9.2 信号与成交

- 月末或周末生成信号。
- 权重从下一交易日开始生效，满足 T+1。
- 周频与月频均可选，默认月频。
- 不使用未来数据计算当日信号。

### 9.3 成本模型

每只股票每个买卖方向分别计算：

- 佣金：成交额的万分之 2，单笔最低 5 元。
- 过户费：成交额的十万分之 1，买入和卖出均计。
- 滑点：成交额的千分之 1，买入和卖出均计。
- 印花税：卖出成交额的千分之 1。
- 冲击成本：按 ADV 参与率和清仓窗口估算。

### 9.4 收益分解

新增以下可追溯字段：

- 毛年化收益：不计交易成本的组合收益。
- 成本拖累：佣金、税费、滑点和冲击成本合计。
- 净年化收益：毛收益扣除成本后的结果。
- 基准年化收益：股票池等权收益。
- 净超额收益：净收益减基准收益。
- 年化换手、最大回撤、夏普和信息比率。

应用必须同时展示毛收益和净收益，避免把未扣成本的漂亮曲线作为最终结论。

### 9.5 容量

- 计算组合容量上限、当前资金占用、剩余容量和最长退出天数。
- 展示 1x、2x、5x、10x 资金压力。
- 说明容量结论只针对当前目标权重和当前流动性环境。

## 10. 研究记录与导出

### 10.1 最近研究记录

本地浏览器保存最近 6 次研究摘要：

- 时间。
- 数据模式。
- 资金与模型。
- 净年化、最大回撤、夏普。
- IC 和成本拖累。
- 完整参数。

用户可以重新载入参数。记录不使用服务器数据库，刷新页面后仍保留。

### 10.2 Markdown 研究报告

导出内容按研究备忘录组织：

1. 研究问题。
2. 数据与样本。
3. 因子与模型。
4. 回测协议和成本。
5. 全样本、探索期、留出期结果。
6. 模型对照。
7. 目标组合。
8. 风险、局限性和下一步验证。

### 10.3 JSON 原始结果

导出完整 API 结果、参数、数据模式和生成时间，供复查和二次分析。前端下载不依赖外部库。

## 11. 展示导览

研究档案页提供“五步展示”按钮，依次聚焦：

1. 研究问题。
2. 数据与血缘。
3. 因子和模型。
4. 回测与收益。
5. 组合、风险和资金计划。

导览只改变滚动位置和步骤状态，不复制页面内容。用户可以随时退出导览。

## 12. 视觉与交互方向

沿用现有“研究纸面量化终端”方向：

- 浅暖灰纸面、深墨色侧栏、金色风险强调。
- 数字使用等宽字体，正文使用中文无衬线字体。
- 页面区块用分隔线和留白建立层级。
- 不使用营销大标题、装饰渐变、光球或玻璃拟态。
- 新增内容仍保持研究备忘录和交易台工具的密度。

交互维持 L1 精致静态：

- 区块入场使用短淡入。
- 按钮、输入框、表格行具备 hover 与 focus 状态。
- 研究完成使用明确状态切换。
- 遵守 `prefers-reduced-motion`。
- 移动端触摸目标不小于 44px。

## 13. 错误处理

- 实时行情失败时保留现有结果，并提示切换到演示数据。
- 演示模式失败属于应用错误，必须显示明确错误。
- 单只股票行情失败时给出股票代码，不静默生成替代价格。
- 导出时若当前没有研究结果，按钮禁用。
- 策略结果同步到组合前检查权重和股票代码。
- 历史记录解析失败时清除损坏记录并继续工作。

## 14. 测试与验收

### 14.1 自动化测试

- 实时结果和演示结果的数据模式字段互不混淆。
- 演示模式不调用外部行情加载器。
- 毛收益不低于净收益，成本拖累为非负。
- 探索期与留出期日期边界正确。
- Markdown 报告包含参数、成本、区段绩效和风险声明。
- JSON 导出可以重新解析。
- 最近研究记录最多保留 6 条并按时间倒序。
- 5 万元整手和最低佣金测试继续通过。
- 风控建议金额和股数换算正确。
- 所有 API 响应可以 `json.dumps(..., allow_nan=False)`。

### 14.2 浏览器验收

- 390px、680px、1280px 无整页横向溢出。
- 实时/演示切换不会清空不相关工作区。
- 搜索、同步风控、导出报告和载入历史记录可用。
- 浏览器控制台无应用脚本错误。
- 不查看截图，仅使用 DOM、尺寸、文本和接口结果检查。

### 14.3 课堂验收

- 断网状态下可在 2 分钟内完成演示模式回测。
- 3 分钟内可讲完五步研究链路。
- 导出文件能直接作为课程报告附件。
- 结论包含收益、风险、成本和局限性，不使用收益承诺。

## 15. 实现边界与风险

- 当前数据源为公开接口，不能保证课堂现场实时可用，因此演示模式是必要功能。
- 固定因子权重不是机器学习训练结果，因此不得使用“训练集准确率”等表述。
- 留出期结果仍然只有一个短样本，不能证明长期稳定。
- 小资金的实际滑点和成交结果可能与模型不同。
- 本应用只用于研究展示，不提供自动交易或投资建议。

## 16. 交付结果

完成后项目应包含：

- 可运行的本地研究应用。
- 实时与演示两种数据模式。
- 可复核的因子、回测和收益分解。
- 组合风控与 5 万元整手执行建议。
- 研究档案、最近记录和报告导出。
- 五步展示导览。
- 更新的 README、DESIGN 和研究方法说明。
- 自动化测试和浏览器验收记录。
