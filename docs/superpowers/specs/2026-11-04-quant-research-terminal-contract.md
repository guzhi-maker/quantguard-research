## 1. 数据模式

策略实验室请求统一携带 `data_mode`，取值为 `live` 或 `demo`。响应必须回显该值，并在 `meta.source`、`meta.generated_at`、`meta.market_data_as_of` 中说明来源与时间。

- `live` 可以访问东方财富公开接口。
- `demo` 的股票池、历史行情、搜索和组合报价都必须来自本机确定性数据，不能回退到外部网络。
- 前端切换模式只改变当前数据源，不删除已输入参数或已生成报告。
- 演示数据固定使用 120 只股票、252 个交易日、固定随机种子 `20261104`，字段与实时行情相同，行业分布固定且包含“未分类”兜底。
- 相同参数在演示模式下必须得到相同结果；生成时间可以变化，但不得作为模型输入。

## 2. 探索期与留出期

令预热后的可交易日序列为：

```text
eligible_dates = dates[60:]
split = floor(len(eligible_dates) * 0.6)
exploration = eligible_dates[:split]
holdout = eligible_dates[split:]
```

- 全样本从 `eligible_dates[0]` 开始计算。
- 三段净值各自以首日 1.0 归一化，探索期与留出期不重叠。
- 留出期可以使用预热期和探索期的历史价格计算因子，但不得使用留出期之后的数据。
- 三段使用完全相同的模型权重、股票池、成本假设和组合约束。
- 留出期结果不做二次调参；探索期只用于解释。
- 若可用长度不足以形成至少一个探索调仓日和一个留出调仓日，返回明确的样本不足错误，不伪造分段。

## 3. 收益字段

回测结果统一提供 `performance.full`、`performance.exploration`、`performance.holdout` 三个对象，每个对象至少包含：

- `gross_annual_return`
- `annual_cost_drag`
- `net_annual_return`
- `benchmark_annual_return`
- `net_excess_annual_return`
- `max_drawdown`
- `annual_volatility`
- `sharpe_ratio`
- `info_ratio`
- `annual_turnover`

`annual_return` 作为净收益兼容字段保留。成本明细至少提供佣金、最低佣金增量、过户费、印花税、滑点和冲击成本的金额及占资金比例，并按买入、卖出方向分别累计。三个区段使用同一组成本假设。

## 4. 组合执行

目标组合与回测使用同一资金、股票池、权重上限、行业上限、ADV 参与率、清仓窗口和成本模型。组合执行页显示实际可买股数、实际金额、剩余现金、整手缺口和预计建仓成本。若现金不足以买入最小一手，明确显示“现金保留”，不生成假仓位。

## 5. 本地研究与导出

最近 6 次记录只保存摘要、参数、模式、数据时间与结果生成时间，不保存完整净值、因子表或原始行情；重新载入时用相同参数重新计算，避免 localStorage 容量不足。

Markdown 报告和 JSON 原始结果都必须带数据模式、行情时间、研究生成时间、参数、成本假设、三段绩效、目标组合、风险与局限性。演示结果必须标注“演示数据”，不构成实时行情或收益承诺。

## 6. 额外验收

- 演示模式在断网状态可运行，且不调用外部行情加载器。
- 实时失败时保留当前结果，并明确提示切换到演示模式。
- 毛收益不低于净收益，成本拖累非负。
- 探索期与留出期边界满足上面的确定公式。
- `json.dumps(..., allow_nan=False)` 可序列化所有 API 响应。
- 390px、680px、1280px 页面无整页横向溢出，表格只在自身容器内滚动。
