# QuantGuard 量化研究方法说明

本文面向课程答辩和代码复核，说明应用如何收集数据、构造样本、训练模型、评估样本外表现，并把预测分数转换为受 A 股约束的组合。

## 1. 研究问题

研究问题定义为：

> 使用价格、波动、流动性和市场状态特征，机器学习模型能否预测未来 20 个交易日的 A 股横截面相对收益，并在计入交易约束后形成正的样本外净超额？

这里预测的不是“股票一定上涨”，而是同一交易日内一只股票相对于股票池平均表现的排序。方法重点是可检验、可复现和不泄漏未来信息。

## 2. 数据来源与模式

### 演示模式

- 120 只合成 A 股风格股票，740 个交易日。
- 随机种子固定为 `20261104`。
- 行业固定为 10 类演示快照。
- 网络完全关闭时仍可运行。
- 页面默认使用 80 只、500 日以控制课堂耗时。

演示模式用于验证软件和研究链路，不代表真实市场规律。

### 实时模式

- 通过东方财富公开行情接口获取高流动性股票池。
- 历史字段包括日期、开盘、最高、最低、收盘、成交量和成交额。
- 默认使用前复权日行情。
- 单只股票失败时保留失败代码，不用其它股票静默替代。
- 行情失败时保留上一次完整结果，并提示切换演示模式。

## 3. 数据审计与清洗

进入特征工程前记录：

- 请求股票数和实际有效股票数。
- 交易日数和日期范围。
- `date + symbol` 重复记录数。
- 非正价格和格式错误记录数。
- 历史长度不足而排除的股票。
- 收盘价、成交额和成交量的缺失率。
- 前向填充单元数量。
- 行业分布和未分类比例。

清洗规则：

1. 删除重复的 `date + symbol`，保留最后一条。
2. 价格必须为正且有限。
3. 成交量和成交额缺失不伪造。
4. 单只股票历史长度不足时整只排除。
5. 时间序列缺口最多前向填充 5 个交易日。
6. 连续特征按当日横截面 Z-Score，并截断到 `[-3, 3]`。
7. 模型缺失值使用训练折中位数填充。

## 4. 特征工程

模型输入为 17 个特征。

### 完整数据底稿

为了让课程展示可以核查本次实验实际使用的数据，每次运行都会生成 `dataset_id`，并保留两份完整快照：

| 视图 | 粒度 | 字段 |
| --- | --- | --- |
| `raw` | 日期 × 股票 | 日期、代码、名称、行业、收盘价、成交额、成交量 |
| `model` | 信号日 × 股票 | 日期、代码、名称、行业、17 个特征、`future_excess`、`label_end_date` |

`raw` 是清洗后进入特征工程的面板，成交额和成交量缺失不会被伪造；收盘价缺口按前述规则处理。`model` 是实际进入时间切分和模型的样本矩阵。

数据审计页支持按代码、名称、行业以及开始/结束日期筛选，每页显示 50 行。筛选在服务端对完整面板执行，不会只搜索当前页。两个视图均可下载完整 CSV。

`future_excess` 和 `label_end_date` 只用于训练目标、时间隔离和样本外评估，不能加入特征矩阵。下载建模样本时需要在后续处理中明确保留这条边界。

数据快照只存在于当前服务进程，最近保留 3 次运行。服务重启或快照被淘汰后，页面会提示重新运行研究，而不是用新数据静默替代旧实验。

### 价格趋势

```text
momentum_5   = close_t / close_{t-5} - 1
momentum_20  = close_t / close_{t-20} - 1
momentum_60  = close_t / close_{t-60} - 1
momentum_120 = close_t / close_{t-120} - 1
price_to_ma20 = close_t / MA20 - 1
price_to_ma60 = close_t / MA60 - 1
```

### 风险

```text
volatility_N = std(daily_return, N) * sqrt(252)
max_drawdown_60 = close_t / rolling_max_60(close) - 1
```

### 流动性

```text
volume_ratio_5_20 = MA5(volume) / MA20(volume)
amount_ratio_5_20 = MA5(amount) / MA20(amount)
liquidity_log_20 = log1p(MA20(amount))
amihud_20 = MA20(abs(daily_return) / amount)
```

### 市场状态

```text
market_return_20 = equal_weight_market_Nav_t / equal_weight_market_Nav_{t-20} - 1
market_breadth = share(close > MA60)
cross_section_dispersion = std(cross_section_return_20)
```

所有特征只使用信号日 `t` 及之前的数据。市场状态特征在当日股票截面上相同。

## 5. 标签与样本

默认标签：

```text
future_return_h = close_{t+h} / close_t - 1
future_excess_h = future_return_h - mean_i(future_return_h,i)
```

其中 `h` 默认是 20 个交易日，可切换为 5、10 或 20。

样本单位为“交易日 × 股票”。构造时必须满足：

- 至少 120 个交易日用于 120 日动量和 60 日波动等特征预热。
- `close_{t+h}` 已经存在。
- `label_end_date <= 训练截止日` 才允许进入训练。
- 未来标签只用于训练目标和评估，绝不能作为特征。

20 日标签窗口会发生重叠，因此有效标签样本数并不等于完全独立事件数。这一点在报告中必须保留。

## 6. 时间切分

应用先按日期升序排列可训练样本，再切分：

- 开发期：最早 60% 的日期。
- 留出期：最后 40% 的日期，只做最终评估。
- 开发期内部再按时间构造 3 个连续验证折。
- 每折训练集只包含验证开始前、且标签已经结束的样本。
- 不随机打乱跨日期样本。

开发期用于：

- 模型类型对照。
- 超参数选择。
- 验证 Rank IC 和 R² 评估。

留出期用于：

- 冻结模型后的样本外验证。
- 检验开发期效果能否复现。
- 最终组合回测。

留出期结果不用于重新选择模型。

## 7. 防泄漏规则

1. 特征只使用信号日及之前的行情。
2. 标准化、缺失填充和行业 One-Hot 只在训练折拟合。
3. 训练样本的标签结束日不得晚于当前信号日。
4. 开发期和留出期日期不重叠。
5. 留出期保持模型类型和超参数不变。
6. 回测使用滚动样本外预测，不使用全样本拟合分数回填历史。
7. 自动化测试用人工构造的未来价格跳变和标签截止时间检查边界。

页面中的泄漏检查卡片会同时展示这些状态。

## 8. 模型

候选模型：

| 模型 | 作用 |
| --- | --- |
| 多因子基线 | 动量、低波动和流动性的固定权重组合 |
| Ridge 回归 | 可解释线性基线 |
| 随机森林 | 非线性树模型，提供排列重要性 |
| 梯度提升 | 非线性交互模型，默认候选 |

监督模型的预处理一致：

```text
17 个数值特征 + 行业
-> 训练折中位数填充
-> 标准化
-> 行业 One-Hot
-> 回归模型
```

Ridge 在开发期比较 `alpha = 0.1, 1, 10, 100`。随机森林和梯度提升使用受限深度或叶子数，避免在小样本上无限生长。随机种子固定，所有候选共享同一训练、验证和评估口径。

## 9. 模型选择

自动选择按以下顺序：

1. 排除训练失败或预测值非有限的候选。
2. 排除验证 R² 明显为负的候选。
3. 在剩余候选中选择开发期验证 Rank IC 最高者。
4. 若监督模型没有超过多因子基线，则保留可解释基线。
5. 留出期开始后不再改模型或超参数。

“入选”只表示开发期选择结果，不表示留出期有效。

## 10. 滚动样本外预测

留出期每 20 个交易日扩展重训一次：

- 训练样本只包含标签已经结束的记录。
- 同一模型类型和超参数保持不变。
- 每次训练记录 `signal_date`、`train_start`、`train_end`、`label_cutoff`、`train_rows` 和 `prediction_rows`。
- 预测在信号日收盘后形成 conceptually，组合从下一交易日生效。
- 回测净值来自滚动预测，避免用未来数据训练后倒填历史。

## 11. 评估指标

### 预测误差

```text
MAE = mean(abs(prediction - future_excess))
RMSE = sqrt(mean((prediction - future_excess)^2))
R2 = 1 - SSE / SST
```

### 横截面排序

每个预测日计算预测分数与实际未来超额收益的 Spearman 相关：

```text
RankIC_t = spearman(prediction_t, future_excess_t)
```

汇总：

- Rank IC 均值。
- Rank IC 标准差。
- ICIR。
- IC 胜率。
- Top-20% 组合的相对超额均值。
- Top-20% 捕获率。

Rank IC 比整体 R² 更贴近选股排序任务。即使 R² 很低，只要排序稳定，也有可能形成正的组合超额；反过来，单个正收益净值不能证明排序能力。

## 12. 从预测到组合

每个调仓日：

1. 按模型预测分数排序。
2. 选择前 `top_n` 只股票。
3. 按逆波动分配初始权重。
4. 应用单票上限 10%。
5. 应用行业上限，默认 22%。
6. 用 ADV、参与率和退出天数计算容量上限。
7. 排除买不起一手的股票。
8. 将权重转换为 A 股 100 股整数手。
9. 未使用金额保留为现金。

实际权重公式：

```text
shares = floor(target_weight * capital / (price * 100)) * 100
actual_weight = shares * price / capital
```

因此小资金账户可能长期持有大量现金，这不是模型仓位建议失败，而是整手交易约束的真实结果。

## 13. 交易成本

成本按每只股票和每个调仓方向计算：

- 比例佣金：成交额万分之 2。
- 最低佣金增量：`max(5 元, 比例佣金) - 比例佣金`。
- 过户费：成交额十万分之 1，双向。
- 印花税：卖出成交额千分之 1。
- 滑点：成交额千分之 1，双向。
- 冲击成本：根据调仓金额、ADV、资金和退出天数估算。

总和：

```text
total_cost = commission + minimum_commission_extra + transfer_fee
           + stamp_tax + slippage + impact
```

比例佣金与最低佣金增量分开显示，保证页面和导出中的成本项可以直接相加。

## 14. 收益与基准

回测同时报告：

- 毛年化收益。
- 成本拖累。
- 净年化收益。
- 等权股票池基准。
- 净超额收益。
- 最大回撤。
- 年化波动。
- 夏普。
- 信息比率。
- 年化换手。
- 容量占用。

研究结论优先看：

```text
样本外排序能力 -> 扣费后净超额 -> 回撤与容量 -> 参数稳定性
```

不看单一净值曲线是否好看。

## 15. 如何正确阅读当前演示结果

最近一次本地验收中，开发期验证 Rank IC 约为 `0.114`，留出期 Rank IC 约为 `-0.009`，留出期净超额为负。应用将其标记为“留出期排序能力没有复现”和“不支持升级”。

这类结果应当原样保留，因为它说明：

- 开发期表现不能自动外推到留出期。
- 一次模型选择可能在样本外失效。
- 回测负结果同样是有价值的研究证据。
- 不能通过反复查看留出期并调参来制造更好结果。

演示结果并不是对真实 A 股的收益判断。

## 16. 复现与实验记录

每次研究生成实验编号，并记录：

- 数据模式、来源、行情截止和演示版本。
- 资金、股票池、窗口、标签期限、模型、调仓和费用参数。
- 数据质量摘要。
- 特征目录与标签定义。
- 模型验证和留出结果。
- 成本、目标持仓、风险和局限。

浏览器保存最近 6 次实验摘要。重新载入历史只恢复参数，不重用旧结果，用户需要重新运行研究。

Markdown 报告适合课程附件，JSON 适合复核原始指标和生成二次图表。

课程答辩需要核查底层数据时，打开“数据审计”中的“完整数据底稿”：先按本次 `dataset_id` 确认实验，再浏览原始行情或建模样本，最后下载完整 CSV。分页只影响浏览，不影响导出范围。

## 17. 课程展示建议

三分钟可按以下顺序讲：

1. **问题**：预测未来 20 日横截面相对收益，而不是猜测绝对涨跌。
2. **数据**：演示与实时模式、数据来源、清洗和缺失审计。
3. **特征与标签**：17 个时点安全特征、未来超额标签、标签截止日。
4. **模型**：多模型对照、开发期选择、留出期冻结和滚动重训。
5. **结果**：验证 IC 与留出 IC 的差异、成本、整手、行业暴露和负结果解释。

现场演示时使用默认 80 只、500 日配置，并在研究运行期间先讲方法和数据设计。

## 18. 局限与下一步

当前局限：

- 股票池按当前流动性筛选，存在幸存者偏差。
- 行业分类不是严格历史时点快照。
- 20 日标签窗口重叠，样本独立性有限。
- 小样本上的树模型和特征重要性可能不稳定。
- 公开行情可能存在延迟。
- 冲击成本模型不能完全复制真实成交。
- 演示数据不代表真实市场。

后续优先验证：

1. 使用历史成分股快照构造无幸存者偏差的股票池。
2. 加入公告日对齐的财务和文本特征。
3. 进行嵌套滚动验证和更严格的模型稳定性检验。
4. 用真实成交记录校验滑点和冲击成本。
5. 把研究结论与组合风险预算分离，避免模型分数直接等同交易指令。

本项目仅用于课程研究和风险观察，不构成投资建议或收益承诺。
